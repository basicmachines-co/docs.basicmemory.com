The Basic Memory package for [Pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) (`@basicmemory/pi-basic-memory`) gives Pi durable continuity: capture a working thread, start fresh later, and recall the decision, rationale, blocker, and next step from a real Basic Memory note. It works over the `bm` CLI by default, or over MCP through `pi-mcp-adapter`.

The package is open source and lives in the basic-memory monorepo — browse the source in [`integrations/pi`](https://github.com/basicmachines-co/basic-memory/tree/main/integrations/pi). New in v0.24.

::tip
Requires Pi 0.85.1 or newer, Node.js 22.19 or newer, and the Basic Memory CLI (v0.24+) on Pi's PATH.
::

---

## Installation

::steps
### Preview the install

```bash
bm install pi --dry-run
```

The preview lists the files it would copy into `~/.pi/agent/packages/basic-memory` and the `pi install` command it would run to register them.

### Install

```bash
bm install pi --yes
```

Use `--local` to register the package in the current workspace's `.pi/settings.json` instead of for your user. If a file you already have differs from the bundled copy, the install stops; review it and rerun with `--replace`. Your Basic Memory config and credentials aren't read or changed.

### Configure the project

Restart Pi and run `/skill:basic-memory-pi-setup`, or create `.pi/basic-memory.json` in the project yourself (see [Configuration](#configuration)).

### Verify

Run `/bm-status` to see the configured project, workspace trust, and whether automatic recall and capture are on.
::

You can also install from a checkout of the repository with `pi install /path/to/basic-memory/integrations/pi`.

## Configuration

Create `.pi/basic-memory.json` in a project you trust:

```json
{
  "transport": "cli",
  "project": "main",
  "captureFolder": "pi/sessions",
  "useHookFlow": true,
  "autoRecall": true,
  "autoCapture": true
}
```

| Key | Default | What it does |
|-----|---------|--------------|
| `transport` | `cli` | `cli` runs the `bm` CLI; `mcp` uses `pi-mcp-adapter` |
| `project` / `projectId` | unset | The Basic Memory project to use (`projectId` wins when both are set) |
| `captureFolder` | `pi/sessions` | Folder for Pi session checkpoints |
| `recallTimeframe` | `7d` | Search window for recall |
| `useHookFlow` | `true` | Use the shared `bm hook --harness pi` lifecycle for automatic recall and capture |
| `autoRecall` | `true` | Recall once before the first agent turn |
| `autoCapture` | `true` | Capture after settled turns and before compaction |
| `captureMinChars` | `80` | Minimum session text before auto-capture |
| `bmPath` / `bmCommand` | `bm` | Override how the CLI is launched |

The package never changes your global Basic Memory default project.

### Workspace trust

Automatic recall and capture run only when **both** of these are true:

- `.pi/basic-memory.json` names a project, and
- the workspace is trusted: `BASIC_MEMORY_PI_TRUST_WORKSPACE=1` is set in Pi's environment.

```bash
BASIC_MEMORY_PI_TRUST_WORKSPACE=1 pi
```

Without them, `/bm-status` reports automatic recall and capture as `blocked` and says why, and manual recall shows setup guidance — nothing falls through to an unrelated default project. Set `autoRecall` or `autoCapture` to `false` and `/bm-status` reports them as `off (configured)`.

Executable overrides from a workspace config (`bmPath`, `bmCommand`) are also gated: set `BASIC_MEMORY_PI_TRUST_BM_COMMAND=1` only in workspaces you trust.

## Commands and tools

| Command or tool | What it does |
|-----------------|--------------|
| `/bm-status` | Show the configured project (or `unconfigured`), workspace trust, and whether automatic recall and capture are on, off, or blocked |
| `/bm-recall [topic]` | Search recent Pi checkpoints and insert them as fenced reference data |
| `/bm-capture [title]` | Save the current working thread as a `pi_session` note |
| `bm_recall` | Recall tool the model can call |
| `bm_capture` | Capture tool the model can call |

The package also ships two Pi skills, `basic-memory-pi` and `basic-memory-pi-setup`, with bundled references for writing notes, capturing, resuming, and tracking tasks.

Recalled notes are inserted as reference data, not instructions.

## MCP mode

To use the Basic Memory MCP server instead of the CLI, install the adapter:

```bash
pi install npm:pi-mcp-adapter
```

Then set the transport:

```json
{
  "transport": "mcp",
  "project": "my-project"
}
```

MCP mode requires an explicit project and `BASIC_MEMORY_PI_TRUST_WORKSPACE=1`. If the adapter isn't installed, Pi keeps working and `/bm-status` reports the missing dependency.
