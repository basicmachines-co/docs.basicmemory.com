Agent skills are ready-made instructions that help your AI assistant use Basic Memory well. They teach it when to save something, how to organize it, and how to pick up where you left off.

Pick the install path for the assistant you use:

- **[Claude](#install-in-claude)** (claude.ai and Claude Desktop): upload [`basic-memory.zip`](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory.zip).
- **[ChatGPT](#install-in-chatgpt)**: upload [`basic-memory-chatgpt.zip`](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory-chatgpt.zip).
- **[Coding agents](#install-in-a-coding-agent)** (Claude Code, Codex, Cursor, and others): install from the terminal with `npx`.

::tip
New to Basic Memory? Once the skill is installed, ask your assistant to help you set up Basic Memory. The [**memory-onboarding**](#individual-skills-optional) guidance interviews you and builds a useful knowledge system for you.
::

## Install in Claude

Skills work in claude.ai and Claude Desktop on the Free, Pro, Max, Team, and Enterprise plans.

**Before you start:** turn on code execution in **Settings → Capabilities → Code execution and file creation**. Skills need it to run. On Enterprise, an organization owner must also enable Skills in **Organization settings → Plugins & skills**.

1. Download [**basic-memory.zip**](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory.zip). Don't unzip it.
2. Open **Customize → Skills** and click **+**.
3. Choose **Create skill → Upload a skill** and select `basic-memory.zip`.
4. Turn the skill on.

`basic-memory.zip` is one combined skill: core Basic Memory guidance, plus the other skills that work with the hosted connector (notes, search, continue, capture, quest, comark, and more) as references Claude reads when it needs them. Claude takes one skill per upload, so this is the easiest way to get everything at once. If you only want one skill, upload its ZIP from [Individual skills](#individual-skills-optional) instead.

[See Claude's walkthrough with screenshots](https://support.claude.com/en/articles/12512180-getting-started-with-skills-on-claude-ai).

## Install in ChatGPT

Uploading skills is available on ChatGPT Business, Enterprise, Healthcare, and Edu. A workspace admin must allow skill uploading.

1. Download [**basic-memory-chatgpt.zip**](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory-chatgpt.zip). Don't unzip it.
2. Open **Plugins** and select the **Skills** tab.
3. Click **Create → Upload from your computer** and select `basic-memory-chatgpt.zip`.
4. Wait for ChatGPT to finish scanning it.

`basic-memory-chatgpt.zip` is the same combined skill as `basic-memory.zip`, plus an `agents/openai.yaml` file that gives it a name and card in ChatGPT. ChatGPT takes one skill per upload; for a single skill, upload its `-chatgpt.zip` from [Individual skills](#individual-skills-optional) instead.

[See the ChatGPT skills walkthrough](https://help.openai.com/en/articles/20001066-skills-in-chatgpt).

::note
ChatGPT Free, Plus, and Pro can't upload skills. You can still [connect Basic Memory Cloud to ChatGPT](/integrations/chatgpt) and add standing guidance as custom instructions; the [AI Assistant Guide](/reference/ai-assistant-guide) has a starting instruction block to paste in.
::

## Install in a coding agent

Claude Code, Codex, Cursor, and other coding agents can install skills from the terminal with `npx`. It ships with Node.js; [install Node.js](https://nodejs.org/en/download) first if needed.

Install every Basic Memory skill:

```bash
npx skills add basicmachines-co/basic-memory/skills -g
```

The `-g` flag installs the skills for your user account, so they're available in every project. Leave it off to install them into the current project only.

Or install one skill:

```bash
npx skills add basicmachines-co/basic-memory/skills --skill memory-onboarding -g
```

List the available skills:

```bash
npx skills add basicmachines-co/basic-memory/skills --list
```

Skills activate automatically when your request matches what they teach. You can also invoke one by name:

- **Claude Code:** `/memory-notes`
- **Codex:** `$memory-notes`

### Install by hand

If you'd rather not use `npx`, download [**basic-memory-skills.zip**](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory-skills.zip) and unzip it into your agent's skills folder. It holds every skill as its own folder. For Claude Code:

```bash
unzip basic-memory-skills.zip -d ~/.claude/skills/
```

[**basic-memory-skills-chatgpt.zip**](https://github.com/basicmachines-co/basic-memory/releases/download/skills-latest/basic-memory-skills-chatgpt.zip) is the same bundle with `agents/openai.yaml` metadata in each skill, for Codex and other OpenAI tools.

::note
Don't confuse the bundles with the combined skill. `basic-memory-skills.zip` and `basic-memory-skills-chatgpt.zip` are folders of many skills for unzipping by hand, and Claude and ChatGPT will reject them as uploads. `basic-memory.zip` and `basic-memory-chatgpt.zip` are a single skill made for uploading.
::

## Use a skill

Skills activate automatically when your request matches what they teach. You can also name the skill directly:

```text
"Use memory-onboarding to help me set up Basic Memory."
"Use memory-notes to write up what we just discussed."
```
