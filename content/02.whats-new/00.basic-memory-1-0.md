**Basic Memory 1.0** turns your knowledge into a workspace your team can read, and keeps it current with agents whose work you can see and review. It's still plain Markdown you own, and every AI tool you connect reads and writes the same notes.

## A wiki for every project

Open any project as a [Wiki](/cloud/wiki): an overview page that links into its decisions, research, meetings, and people, a page for every folder, and a change log. Basic Memory keeps those `index.md` and `log.md` files current as your notes change.

## Live notes

Put a KPI, a Gantt chart, a comparison, or a task board inside any note with [Comark](https://comark.dev/) components. The data stays in the note as ordinary lists and tables, and **live views** run a query over your project each time you open them. See [Live Notes](/cloud/live-notes).

::

## Documents become notes

Upload a PDF, Word, PowerPoint, or CSV file and Basic Memory extracts it into a searchable note next to the original, so your AI can read and cite what's inside. See [Documents and PDFs](/concepts/documents-and-pdfs).

## Basic Memory agents (beta)

[Agents](/agents/about) look after your notes. An agent is a note with instructions; it runs when a new note lands in a folder it watches, or when you start it. Ready-made agents handle meeting follow-up, linking, cleanup, a weekly reflection, and schema drift. Every change lands in a shared review queue, where you keep it or undo it, and runs bill credits only when they finish.

## People and agents on the same page

- **[Comments and suggestions](/cloud/comments-and-suggestions)**: people and agents suggest edits in the note, stored as CriticMarkup in the Markdown file, and anyone with access accepts or rejects them.
- **[Pocketbook](/cloud/mcp-app)**: the Basic Memory app inside Claude and ChatGPT, to browse, search, graph, and read your notes without leaving the conversation.
- **[Browser agents](/cloud/browser-agents)**: in browsers that support WebMCP, the web app gives browser agents tools to search and read notes and suggest edits, acting as you.

## Open Knowledge Format

Basic Memory speaks the [Open Knowledge Format](/concepts/knowledge-format#open-knowledge-format-okf) (OKF): the wiki's index and log files follow it, and `bm okf export` writes a project as an OKF bundle that any OKF tool can read.

## Plans and usage credits

Cloud ($19), Pro ($99), and Business ($250) each include usage credits, a member limit, and a spending limit you set. **Settings → Usage** shows where every credit went, by person, API key, agent, and background job. See [Plans and Billing](/teams/seats-and-billing) and [Usage and Credits](/cloud/usage-and-credits).

## New MCP tools

1.0 consolidates the MCP tools into the `bm_*` set (`bm_read`, `bm_write`, `bm_edit`, `bm_search`, `bm_context`, and more). If you've configured clients or written agent instructions against the older tool names, see [Migrating to 1.0](/reference/migrating-to-1-0).
