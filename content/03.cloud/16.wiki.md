The **Wiki** opens a project as a set of pages to read, instead of a folder of files. Every project gets an overview page that links into its folders and notes, every folder gets a page of its own, and a change log records what's new. Anyone on the workspace can find their way around, and every page is still a Markdown note your AI tools read and write.

::theme-image{light="/screenshots/cloud-app/wiki-overview-light.png" dark="/screenshots/cloud-app/wiki-overview-dark.png" alt="The Harbor launch project opened as a wiki: an overview page linking to its decisions, people, research, and meetings"}
::

## Open a project as a wiki

Choose **Wiki** in the app's navigation. The Wiki opens on one project at a time:

- **The project's overview page** loads first. It's the project's root `index.md`.
- **The sidebar** lists that project's folders and notes. Choosing a folder opens its page.
- **Search** sits at the top of the sidebar, with the same keyboard shortcut as the rest of the app.
- **Each page** reads in a single column with breadcrumbs and, for longer notes, an outline of its headings.
- **To switch projects**, open the menu at the top of the sidebar.

Pages render the same way they do in Notes, including [live notes](/cloud/live-notes) components. To change a page, choose its **Edit** action; it opens the same note in the editor.

## Index and log pages Basic Memory keeps current

The overview, folder pages, and change log are ordinary Markdown files in your project:

- **`index.md`** in the project root and in each folder lists what's in it, with standard Markdown links.
- **`log.md`** records recent changes under date headings, newest first, up to the 25 most recent.

In Basic Memory Cloud you don't run anything to keep them current. When notes are saved, folders are created, a project is created, or an import finishes, Basic Memory rewrites the affected `index.md` and `log.md` files in the background. Settings → Usage lists this work as **Wiki pages**.

::note
Basic Memory never overwrites an `index.md` or `log.md` you wrote yourself. It only replaces files it generated. For a local project, run `bm wiki rebuild` to generate the same pages; local and cloud produce the same files. See the [CLI Reference](/reference/cli-reference).
::

These files follow the [Open Knowledge Format](/concepts/knowledge-format#open-knowledge-format-okf) (OKF): the root `index.md` carries `okf_version: "0.2"`, so any tool or agent that reads OKF can walk the project one level at a time instead of loading every note.
