Basic Memory's web app supports **WebMCP**, a browser standard that lets a page offer tools to an AI agent running in the browser. When your browser supports it, an agent working in the Basic Memory tab can use the app directly instead of clicking through it.

::note
WebMCP is new and experimental. In Chrome, it needs the WebMCP testing API turned on; check your browser's documentation for its support. There's nothing to set up in Basic Memory: the tools register as soon as the browser supports them.
::

## How browser agents act

A browser agent acts **as you**: it's scoped to the signed-in person, the workspace that's open, and the page you're on. It can only reach notes you can reach, and it changes nothing on its own.

- **Suggestions, not edits.** An agent's changes to a note arrive as [suggestions](/cloud/comments-and-suggestions) you accept or reject.
- **Component changes wait for you.** A proposed change to a live note component opens side by side with the original; only your **Apply** changes the note.
- **Sign-in, purchases, and terms stay yours.** The agent can open the sign-up, login, or subscription page, but you complete credentials, verification, and any purchase.

After you move to another page, workspace, or account, the agent rediscovers the tools for where you are.

## The tools

| Tool | What it does |
| --- | --- |
| **Note tools** | Search, list, open, and read notes; read a note's version history; suggest edits to the open note |
| **`basic_memory.wiki`** | Report the Wiki's state, open a project in the Wiki, and switch between reading and editing |
| **`basic_memory.comark`** | Check the open note's [live notes](/cloud/live-notes) components: which are valid, what's wrong, and whether each live view has current data |
| **`basic_memory.propose_component_change`** | Propose a change to one component, shown beside the original for you to apply or cancel |
| **`basic_memory.account`** | Report sign-in state and open the sign-up, login, or subscription page |
| **`basic_memory.snapshots`** | List a workspace's [snapshots](/cloud/cloud-snapshots) and download one as a ZIP. It can't restore or delete them |

Your other AI tools keep using Basic Memory over MCP as usual. WebMCP adds a way for agents that live in the browser to work with the app you already have open.
